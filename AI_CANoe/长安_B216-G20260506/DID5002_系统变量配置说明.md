# DID5002 配置写入功能 - 系统变量配置说明

## 功能概述
实现 2E 50 02 服务，写入 64 字节 DID 数据，其中：
- byte10、byte44、byte46 从 Panel 下拉框取值
- 其他 61 字节固定为 0x00

## 需要创建的系统变量

### 1. DiagControl 命名空间（3个配置值）

| 变量名 | 类型 | 取值范围 | 说明 |
|--------|------|----------|------|
| `DiagControl::DID5002_Byte10` | int | 0x00, 0x05, 0x29, 0x30... | 配置字节10 |
| `DiagControl::DID5002_Byte44` | int | 0x00, 0x05, 0x29, 0x30... | 配置字节44 |
| `DiagControl::DID5002_Byte46` | int | 0x00, 0x05, 0x29, 0x30... | 配置字节46 |

**建议下拉框选项：**
```
0x00 - 未配置
0x05 - 某功能开启
0x29 - 油车配置
0x30 - 电车配置
```

### 2. Button 命名空间（1个按钮）

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `Button::Button_FL_5002` | int | 触发DID5002写入的按钮 |

## Panel 控件绑定

### ComboBox（下拉框）配置

**ComboBox 1 - Byte10 配置：**
- 绑定变量：`DiagControl::DID5002_Byte10`
- 选项：
  - 显示文本："未配置 (0x00)"，值：0
  - 显示文本："功能开启 (0x05)"，值：5
  - 显示文本："油车 (0x29)"，值：41
  - 显示文本："电车 (0x30)"，值：48

**ComboBox 2 - Byte44 配置：**
- 绑定变量：`DiagControl::DID5002_Byte44`
- 选项同上

**ComboBox 3 - Byte46 配置：**
- 绑定变量：`DiagControl::DID5002_Byte46`
- 选项同上

### Button 配置

**Button - 触发写入：**
- 绑定变量：`Button::Button_FL_5002`
- 类型：Push Button
- 文本："写入 DID5002"

### Output/Input 控件（显示结果）

建议在 Panel 上添加以下显示控件：

| 控件类型 | 变量名 | 说明 |
|----------|--------|------|
| Output | `FL_DID5002_Result` | 显示"写入成功"或"写入失败" |
| Output | `FL_DID5002_Status` | 显示"PASS"或"FAIL" |

## 数据映射关系

```
UDS 请求帧结构（67字节总长度）：
┌─────────────────────────────────────────────────────────────┐
│ Byte 0-2: 2E 50 02 (SID + DID)                              │
│ Byte 3-66: 64字节 payload                                   │
│   ├─ Byte 13 (payload[10]): DiagControl::DID5002_Byte10     │
│   ├─ Byte 47 (payload[44]): DiagControl::DID5002_Byte44     │
│   └─ Byte 49 (payload[46]): DiagControl::DID5002_Byte46     │
│   └─ 其他61字节: 0x00                                       │
└─────────────────────────────────────────────────────────────┘

ISO-TP 多帧发送：
- 首帧 (FF): 10 43 2E 50 02 XX XX XX (6字节数据)
- CF1: 21 XX XX XX XX XX XX XX (7字节)
- CF2: 22 XX XX XX XX XX XX XX (7字节)
- ...
- CF9: 29 XX XX XX XX 00 00 00 (最后帧，剩余5字节有效)
```

## 响应处理

ECU 正响应：`6E 50 02`（写入确认）
ECU 负响应：`7F 2E XX`（NRC错误码）

## 测试步骤

1. 在 Panel 上选择 3 个配置值
2. 点击"写入 DID5002"按钮
3. 观察 Write 窗口发送的帧序列：
   - 首帧：10 43 2E 50 02 ...
   - 流控帧：30 00 0X（ECU响应）
   - 连续帧：21 ... 22 ... 29 ...
4. 等待 ECU 响应：6E 50 02
5. 查看 Panel 显示结果

## 注意事项

1. 必须先进入扩展诊断会话 (10 03)
2. 建议先完成安全访问 (27 01/02)
3. 67字节数据需要 1个首帧 + 9个连续帧 完成传输
4. 如果 ECU 返回负响应 (7F 2E XX)，查看 NRC 码含义
