# SmartCharging (智能充电) 样例工程使用说明

本目录包含 CANoe 针对新能源电动汽车与充电桩(EVSE)通信交互标准的仿真工程。能够实现充电时序控制和充电状态协议模拟。

## 1. DIN70121_ISO15118
**功能简介**：
演示基于欧美标准的 CCS (Combined Charging System) 联合充电系统通信：
- **DIN 70121**：直流快速充电标准。
- **ISO 15118**：支持更高级功能的交/直流充电标准，包括即插即充(Plug & Charge)、V2G (Vehicle to Grid) 及证书加密的安全认证流程。工程包含基于底层 HomePlug Green PHY 电力线载波(PLC)或以太网等协议层面的模拟交互。

## 2. GBT27930
**功能简介**：
演示基于中国国家标准的 GB/T 27930 直流充电通信协议（基于物理 CAN 总线）。演示了充电桩与电动车 BMS(电池管理系统) 间的握手、参数配置、充电阶段及错误处理整个状态机时序。

**使用说明**：
打开对应协议的 `.cfg` 工程。CANoe 提供了专门的 Smart Charging 监控及配置界面，用户可以通过面板改变充电握手状态及相关电压/电流等请求参数，以便验证充电时序的合规性。
