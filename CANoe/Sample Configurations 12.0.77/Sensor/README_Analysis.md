# Sensor 样例工程使用说明

本目录包含针对车载传感器常用低速及同步串行总线协议的仿真工程。配合相应的 Vector Sensor 硬件板卡模块（如 VT2710）可以进行传感器级别的硬在环仿真。

## 1. SENT (Single Edge Nibble Transmission)
**功能简介**：
演示 SENT 协议，这是一种典型的点对点单向传输方案，主要用于如节气门位置传感器、温度传感器、压力传感器等高速、高精度和低成本的数字信号传输。

## 2. PSI5 (Peripheral Sensor Interface 5)
**功能简介**：
演示 PSI5 协议，该协议具备较高的数据传输速率和可靠性，支持两线电流调制通信，常用于安全系统（如安全气囊控制器与碰撞传感器间的通信）。

## 3. SPI (Serial Peripheral Interface)
**功能简介**：
演示基于标准 SPI 同步串行总线的微控制器与外围传感器/芯片级别的短距离通信仿真。

**使用说明**：
进入相关协议目录，打开 `.cfg` 工程。在无硬件连接时，可在 CANoe 的 Trace 和状态窗口中观察逻辑层面的报文解析及调度机制。配合硬件时，可真实模拟传感器电压/电流调制波形。
